# 🔍 Lost & Found Portal for College

An intuitive, full-stack web application designed for college campuses to help students and staff report, search, and recover lost and found items.

---

## 🌐 Live Demo & Deployment Links

- **🚀 Live Web App**: [https://lost-found-portal-for-college.vercel.app](https://lost-found-portal-for-college.vercel.app)
- **⚡ Vercel Deployment Overview**: [https://vercel.com/thahir3/lost-found-portal-for-college](https://vercel.com/thahir3/lost-found-portal-for-college)

---

## ✨ Features

- **🔐 User & Admin Authentication**: Secure login/registration system with role-based access.
- **📦 Lost Item Reports**: Students can log details about items lost on campus with descriptions, location, and images.
- **🔍 Found Item Reports**: Anyone who finds an item can log its details and image.
- **🔔 Real-time Notifications**: Notify owners when matching items are found or claimed.
- **🛡️ Admin Dashboard**: Admin panel to review reports, resolve tickets, and manage platform listings.
- **📱 Responsive UI**: Modern, user-friendly design tailored for desktop and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Database**: SQLite (`better-sqlite3`)
- **File Uploads**: Multer
- **Deployment**: Vercel

## 💻 Local Setup Instructions

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/thahirahamed33-tech/Lost-Found-Portal-for-College.git
   cd Lost-Found-Portal-for-College
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   node server.js
   ```

4. **Access in Browser:**
   Open [http://localhost:3000](http://localhost:3000)
